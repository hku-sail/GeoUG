# GeoUG training: data card and recipes

[Back to the project README](../README.md)

This guide brings together the training data releases, environment setup, and
SFT / RL launch instructions. Run all commands from the **GeoUG checkout root**.
The public starting point for spatial-policy RL is
[GeoUG-ColdStart](https://huggingface.co/rayruiyang/GeoUG-ColdStart), the supervised
cold-start checkpoint.

## Training data card

### Training datasets and supporting artifacts

| Dataset / artifact | Stage | Download | Notes / contents |
|---|---|---|---|
| **GeoUG cold start data** | SFT | Coming soon | COCO- and ADE20K-derived interleaved spatial reasoning samples. [Manifest format](../configs/sft/datasets.example.json). |
| **GeoUG Spatial RL data** | RL | [Hugging Face][data-rl] | `train_geoug_rl.parquet`: 800 training samples with images, camera metadata, and losslessly embedded generated-depth caches. Unpack before training; prepare validation/evaluation data separately. [RL guide](RL_TRAINING.md). |

The links above distinguish downloadable releases from local preparation steps.
The internal RL evaluation subset and geometric co-training / VLM manifests are
not included in the public release. Upstream dataset terms remain applicable.

## Training data sources and use

The public RL parquet contains 400 `scannetpp_train` samples and 400
`nuscenes_train` samples. It bundles image bytes, questions and options, camera
intrinsics with their calibration dimensions, and generated-depth NumPy caches.
The caches are model-generated training assets, not ground-truth depth labels.
See the [Hugging Face data card][data-rl] for the complete schema and source
attribution. Cold start data consists of COCO- and ADE20K-derived interleaved
reasoning samples and is not yet released.

## Environment setup

Use Python 3.10 or 3.11 and the dependency set for the training stage. CUDA and
FlashAttention are required; see [standalone setup](STANDALONE.md) for details.

```bash
# SFT environment
python -m venv .venv-sft
source .venv-sft/bin/activate
pip install -r requirements.txt
pip install flash_attn==2.5.8 --no-build-isolation
```

Use a separate environment for RL:

```bash
python -m venv .venv-rl
source .venv-rl/bin/activate
pip install -r requirements-rl.txt
pip install flash_attn==2.5.8 --no-build-isolation
```

## Download the public RL inputs

```python
from huggingface_hub import hf_hub_download, snapshot_download

snapshot_download(
    repo_id="rayruiyang/GeoUG-ColdStart",
    revision="bc482a34918e9fe3801ad59384609e772bcb0f2d",
    local_dir="ckpt/geoug-coldstart",
)
hf_hub_download(
    repo_id="rayruiyang/GeoUG_data",
    repo_type="dataset",
    filename="train_geoug_rl.parquet",
    revision="645751a91a0813b08167ea8cc34b89285c69e70b",
    local_dir="artifacts/geoug-spatial-rl",
)
```

Restore the runtime layout from the single release parquet:

```bash
python scripts/pack_data_parquet.py unpack-rl \
  --input artifacts/geoug-spatial-rl/train_geoug_rl.parquet \
  --output outputs/rl_train
```

The output directory must not already exist. The command creates:

```text
outputs/rl_train/
├── train.parquet
├── camera_table.json
└── depth-cache/
```

Supply your own `validate.parquet` and matching camera-table entries for the
training runtime, plus evaluation questions and depth caches for online
assessment. These are not generated by unpacking the public training split.
See [required RL dataset layout](RL_TRAINING.md#required-dataset-layout) and
the detailed evaluation instructions in that guide.

## Training recipes

### SFT

Copy `configs/sft/datasets.example.json`, replace all dataset and parquet-index
paths, and launch:

```bash
MODEL_PATH=/path/to/v5-step-1000 \
GEOUG_DATASET_MANIFEST=/path/to/datasets.json \
NNODES=2 \
NPROC_PER_NODE=8 \
bash scripts/train_sft.sh
```

`NUM_SHARD` defaults to `NNODES × NPROC_PER_NODE`, so the launcher works for
both single-node smoke tests and the 16-GPU paper recipe. Full-parameter SFT
does not fit on 4×A100-80GB with AdamW and EMA; the released recipe was trained
with 16 GPUs. A memory-bounded 4-GPU smoke test can freeze the large backbones:

```bash
bash scripts/train_sft.sh \
  --total_steps 1 \
  --freeze_llm True \
  --freeze_vit True
```

The public model release starts at GeoUG-ColdStart.
Reproducing the earlier SFT stage requires the original v5 initialization and
training inputs, which are not included in these model packages. Use
GeoUG-ColdStart to initialize the released RL recipe.
See the [SFT implementation guide](../train/sft/README.md).

### RL

RL starts from [GeoUG-ColdStart][model-sft-init]. Download
`train_geoug_rl.parquet` from [GeoUG_data][data-rl] and unpack it using the
[RL guide](RL_TRAINING.md) to restore the training parquet, camera metadata,
and depth cache. Supply your own validation/evaluation data:

```bash
MODEL_PATH="$PWD/ckpt/geoug-coldstart" \
RL_DATASET="$PWD/outputs/rl_train" \
DEPTH_CACHE_DIR="$PWD/outputs/rl_train/depth-cache" \
EVAL_QUESTIONS=/path/to/eval_questions.parquet \
EVAL_DEPTH_CACHE=/path/to/eval_depth_cache \
LAMBDA_COST=0.1 \
NPROC_PER_NODE=8 \
bash scripts/train_rl.sh
```

The final method is `spatial_gate_draft_v3`: draft tokens receive zero
advantage, grounding uses depth-branch credit, and the gate uses a forced
two-branch counterfactual estimate. See the [detailed RL guide](RL_TRAINING.md).

[data-rl]: https://huggingface.co/datasets/rayruiyang/GeoUG_data
[model-sft-init]: https://huggingface.co/rayruiyang/GeoUG-ColdStart
